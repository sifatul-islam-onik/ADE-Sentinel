# results/

Every number the project measured.

| | |
|---|---|
| `runs.csv` | **the master log** — one row per experiment, with its score, hyperparameters, seed and git commit. The notebooks read their tables from here. |
| `figures/*.png` | the charts, shown in notebooks 4-6 |
| `figures/*.md` | the detailed write-up behind each chart |
| `dataset_stats.md`, `split_report.md`, `corpus_prep_stats.md` | measured statistics of the corpus and the frozen split |
| `error_taxonomy.md`, `error_sample.csv` | 30 end-to-end failures, read and categorised |
| `bio_conversion_report.md` | what the character-span → BIO conversion did across the corpus |

These files were produced by the original build scripts, which is why some of them open
with a line like *"Generated by `scripts/stage1_report.py`"*. Those scripts are not in this
branch — it keeps the notebooks and the demo only — but they remain in the project's git
history. The numbers are unchanged, and notebooks 4-6 recompute the main ones live from the
saved checkpoints, so you can check them against these files.
