# Pipeline error taxonomy (step 6.4, run 12)

Generated by `scripts/error_taxonomy.py` from run 12's pipeline output - Stage 1 run 8 as the gate, Stage 2 run 11 as the tagger. A sentence is a **failure** when the pipeline's entity set for it differs from the gold set.

**269 of 3,133 test sentences are failures**: 40 ADE sentences the gate rejected, 85 non-ADE sentences it passed and Stage 2 tagged, and 144 of the 600 passed ADE sentences with at least one entity error.

PLAN 6.4 lists negation, hedging, multi-drug, abbreviation and boundary as the categories. They are two different things, so they are reported separately: *boundary* is a property of the error, decided exactly by the tags; the other four are properties of the sentence, decided by frozen surface rules, and a sentence having one does not show that it caused the error.

## What the failing sentences contain

Each cell compares the rate of a sentence property among failures with its rate among successes **in the same population**, with Fisher's exact test. For ADE sentences the drug count and abbreviation flag are read off the gold entities, so a tagger's own mistakes cannot create them. 10 tests are run, so a Bonferroni threshold of p < 0.0050 is the bar for calling any single difference real.

| Property | Gate misses vs gate hits (ADE sentences) | Gate false alarms vs correct rejections (non-ADE sentences) | Stage 2 errors vs successes (passed ADE sentences) |
|---|---|---|---|
| negation cue | 7.5% vs 3.7% (OR 2.13, p = 0.201) | 9.4% vs 9.9% (OR 0.94, p = 1.000) | 4.2% vs 3.5% (OR 1.20, p = 0.799) |
| hedging cue | 20.0% vs 14.3% (OR 1.49, p = 0.354) | 15.3% vs 11.4% (OR 1.40, p = 0.298) | 22.2% vs 11.8% (OR 2.13, p = 0.004) |
| two or more drugs | 12.5% vs 17.2% (OR 0.69, p = 0.662) | - | 21.5% vs 15.8% (OR 1.46, p = 0.128) |
| abbreviation in an entity | 20.0% vs 13.8% (OR 1.56, p = 0.346) | - | 14.6% vs 13.6% (OR 1.08, p = 0.782) |

Differences that clear the Bonferroni threshold: **hedging cue** among Stage 2 errors (22.2% vs 11.8%, p = 0.004).

## Threats to validity

| Threat | Status |
|---|---|
| Sentence properties read as causes | controlled in the text - reported as co-occurrence with a significance test; causes come only from reading the sampled sentences, in *Causes, from reading the sample* |
| Causes come from a single reader | not controlled - drafted by an AI coding agent from the sentence text; not yet reviewed by the authors; there is no second reader and no agreement check |
| Ambiguous readings | not controlled - 10 of the 30 readings are marked [low confidence], where two categories were close or the sentence reads two ways |
| Cue and abbreviation rules are surface patterns | not controlled - a cue need not scope over the relation; an all-caps token need not be an abbreviation |
| Comparisons confounded by the gate's class mix | controlled - each comparison stays inside one population |
| Many comparisons | controlled - Bonferroni over 10 tests |
| Thirty is a small sample | by design - the sample is for reading; every rate outside *Causes, from reading the sample* uses all 269 failures, and the shares inside it carry Wilson intervals |
